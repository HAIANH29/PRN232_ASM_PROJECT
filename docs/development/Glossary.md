# Glossary

| Term | Meaning |
| --- | --- |
| Approved knowledge | Admin-reviewed guidelines, foods, recipes and regimens that the platform may use for advice |
| Diet regimen | A structured eating approach a user can follow and track |
| Meal plan | A user's planned meals over a period |
| Tracking | Recording daily and per-meal adherence and progress |
| Book source | An uploaded book file ingested by an Admin into knowledge candidates |
| Vector DB | The pgvector database used for semantic search over approved knowledge |
| Gateway | The YARP reverse proxy that is the single backend entry point |
| Fallback recommendation | Safe response used when Gemini is disabled or unavailable |
