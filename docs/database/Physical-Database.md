# Physical Database

PostgreSQL is used with database-per-service ownership.

## IdentityDb

- `Users`
- `Roles`
- User-role join table generated by EF Core

Owned by `Identity Service`.

## DietKnowledgeDb

- `DietGuidelines`
- `Foods`
- `Recipes`
- `RecipeIngredients`

Owned by `Diet Knowledge Service`.

## MealPlanningDb

- `MealPlans`
- `MealPlanItems`

Owned by `Meal Planning Service`.

`UserId`, `RecipeId`, and `FoodId` are cross-service identifiers only.

## TrackingDb

- `DailyTrackings`
- `MealTrackings`

Owned by `Tracking Service`.

`MealPlanItemId` is a cross-service identifier only.

## Rules

- No service reads another service database directly.
- No cross-database foreign keys.
- EF Core migrations should be created per service in a later implementation phase.
